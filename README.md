# System Design for Agentic AI: companion code

Companion repository for *System Design for Agentic AI: The Book and Interview Guide for Distributed Foundations, Models as Components, Knowledge and Memory, Harnesses and Loops, Control Planes and Twelve Worked Architectures* by Rajesh Ranjan Mahapatra (AI at Work series).

- `designlab/` – the system built across the book, chapter by chapter, against the synthetic Lakeshore Travel Group corpus.
- `figures/src/` – source for every figure (Graphviz, PlantUML, matplotlib), rendered by `build/render_figures.py`.
- `build/` – the Kindle EPUB build pipeline.

Work in progress; updated as chapters are written.
